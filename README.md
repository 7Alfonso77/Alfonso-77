# Contador de sushis 🍣

Aplicación sencilla y bonita para contar cuántos sushis te comes haciendo tap en la pantalla.

## Cómo usarla (sin programar)

Solo necesitas un navegador (Chrome, Firefox, Edge o Safari).

### Opción 1: Abrir el archivo directamente

1. Entra en la carpeta del proyecto.
2. Haz doble clic en `index.html`.
3. Se abrirá en tu navegador y podrás tocar la pantalla para sumar sushis.

### Opción 2: Usar un mini servidor local (opcional)

Si prefieres abrirlo como una mini app local:

1. Abre una terminal en la carpeta del proyecto.
2. Ejecuta:
   ```bash
   python -m http.server 8000
   ```
3. Abre tu navegador y entra en: `http://localhost:8000`.

## Qué hacer en la app

- **Tap en la pantalla** para sumar un sushi.
- **Sumar sushi**: botón para sumar manualmente.
- **Reiniciar**: vuelve el contador a cero.

¡Listo! 🎉
